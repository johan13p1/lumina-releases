Capes in this folder ship with Lumina and show up in the Cosmetics page for everyone.
PNG (2:1 or the LabyMod format 22:17, any size), animated PNG (APNG), a PNG with frames stacked vertically (100 ms each) or an animated GIF.
The file name becomes the display name (aurora_borealis.png -> "Aurora Borealis").
order.txt sets the order on the Cosmetics pages; capes not listed there follow alphabetically.
